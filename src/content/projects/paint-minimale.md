## About the project

A super minimal take on Paint, with a start screen and two basic tools.

### Features

- **Draw** by holding the left mouse button and moving the mouse.
- **Erase** by clicking the right mouse button.
- A start screen before the canvas.

### Technical notes

Written in C++20 with SFML 2.5.1. On Linux it builds with `make all`; on Windows a `start.bat` script compiles it with MinGW-w64. The README is available in Italian and English.
