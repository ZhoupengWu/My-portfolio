## About the project

stageMatch makes it easier for students and companies to find each other. Students build a profile with their skills, preferences and availability, companies publish internship offers, and the app works out the most relevant matches.

### Features

- **Student profiles:** technical and soft skills, spoken languages (with CEFR level), past experiences and address history.
- **Company profiles:** sign-up with Google OAuth and a one-time access code generated by an admin, plus management of internship listings.
- **Listings and applications:** companies set skill requirements with a minimum level; students apply and companies track the status of each application.
- **Matching engine:** each student/listing pair gets a deterministic score based on skills, soft skills and commute time. An AI model can optionally refine it, within a limited margin, and the deterministic score is always the fallback.
- **Maps and routes:** address autocomplete, geocoding and home-to-company routes, handled by an internal proxy service.
- **Notifications and privacy:** in-app notifications, tracked privacy consent, JSON export of personal data and account deletion.

### Architecture

The app is made of two independent Flask processes: the main application, which serves the pages, handles authentication and is the only one that touches the database, and an internal geo proxy that wraps the external geographic APIs. The matching engine runs in the background on an in-memory queue so it never blocks HTTP requests. The frontend is plain HTML, CSS and JavaScript with Jinja templates, and everything starts together with Docker Compose.
