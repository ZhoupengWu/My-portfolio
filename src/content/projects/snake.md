## About the project

A Snake game implemented in C++ using the winbgim.h graphics library. Guide the snake to eat food, avoid the edges and your own body, and aim for the highest score.

### Features

- Simple graphics
- Arrow-key controls
- Real-time score tracking
- Game over on collision
- Random food generation on the grid

### Development process

I started with the structure of the snake and the game area, then wrote the food generation and the direction changes. After that I added the logic that keeps the snake alive and a function to display the score.

The game runs on Windows and is built with Dev-C++.
