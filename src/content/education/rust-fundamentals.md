## About the repository

A practical and theoretical path through the basics of Rust, organized by the chapters of the official [*The Rust Programming Language*](https://doc.rust-lang.org/book/) book. Every topic has its own Cargo project, and the README works as a complete review guide covering the theory, compiler rules, memory model and syntax. It is written in Italian.

### What it covers so far

- **Getting started:** Hello World with `rustc`, Cargo projects and commands, and a guessing game with an external crate.
- **Common concepts:** variables and mutability, data types, functions, and control flow, plus exercises such as a Celsius/Fahrenheit converter and Fibonacci numbers.
- **Ownership:** ownership and move semantics, references and borrowing, and slices.
- **Structs and methods:** custom types, `#[derive(Debug)]`, methods and associated functions.
- **Enums and pattern matching:** enums, `match`, `if let` and `let...else`.
- **Extras:** an ASCII-art heart drawn with nested loops.
