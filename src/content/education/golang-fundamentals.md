## About the repository

A collection of small Go modules, one per topic, tied together with a Go workspace. I use it to learn the language by writing code for each concept.

### What it covers so far

- **Language basics:** variables (with `const` and `iota`), functions, control structures, arrays and collections.
- **Types:** structs, pointers and interfaces.
- **Testing:** tested exercises such as FizzBuzz, Roman numerals and a sum function.
- **Web:** a minimal `net/http` server with a `/ping` endpoint, and two URL shortener APIs, one of which stores its data in PostgreSQL using Gin and GORM.

Work in progress: I keep adding topics as I study.
